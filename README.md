# نظام إدارة المتجر والمخزون

نظام متكامل لإدارة المتاجر والمخزون للمشاريع الصغيرة والمتوسطة — **عربي بالكامل** مع دعم RTL، ويعمل **محلياً بدون باك-إند** أو اشتراك أو حساب.

يُدار بالكامل من خلال المتصفح باستخدام HTML و CSS و JavaScript النقي (بدون أطر عمل)، ويُخزّن كل شيء في `IndexedDB` على جهاز المستخدم. مناسب للنشر على **GitHub Pages** ويعمل على **أندرويد، آيفون، كمبيوتر**.

---

## ✨ المميزات الرئيسية

### نقطة البيع والفواتير
- واجهة POS عربية كاملة مع بحث بالاسم/الرمز/الباركود.
- سلة مشتريات ديناميكية، خصومات على السطر والفاتورة، ضريبة قابلة للإعداد.
- طرق دفع متعددة: نقدي، فودافون كاش، إنستا باي، تحويل بنكي، آجل.
- دفع جزئي، آجل، ومتابعة الرصيد المستحق.
- إنشاء فاتورة برقم تلقائي، خصم فوري من المخزون، وتسجيل الحركة.
- طباعة الفاتورة (A4 / حرارية 80mm) عبر `window.print()`.
- حفظ كملف PDF عبر "حفظ كـ PDF" في نافذة الطباعة.
- مشاركة عبر واتساب مع رسالة عربية جاهزة (wa.me).

### المنتجات والمخزون
- CRUD كامل للمنتجات مع بحث، فلترة، فرز، وترقيم صفحات.
- حقول: الرمز، الاسم، الفئة، الباركود، سعة الشراء والبيع، الكمية، الحد الأدنى، الوحدة، تاريخ الانتهاء، المورد، ملاحظات.
- منع تكرار الرمز (SKU).
- رصد المخزون المنخفض والمنتهي الصلاحية تلقائياً.
- دعم الكسور العشرية للوحدات بالوزن/الحجم.

### الاستيراد الجماعي من Excel
- تنزيل **قالب Excel عربي** بالأعمدة الصحيحة.
- استيراد ملفات `.xlsx`, `.xls`, `.csv`.
- معاينة قبل التنفيذ + تقرير أخطاء قابل للتنزيل.
- قواعد دمج ذكية للمنتجات الموجودة (افتراضي: إضافة الكميات).
- خيارات: تحديث البيانات فقط / تحديث + إضافة كميات / استبدال الكمية / تخطّي.
- تسجيل كل حركة مخزون مع **رقم دفعة استيراد**.
- إمكانية **التراجع عن الاستيراد** بأمان (مع فحص الحركات اللاحقة).

### المشتريات والموردون
- إدارة كاملة للموردين مع متابعة الأرصدة المستحقة.
- فواتير شراء مع تحديث المخزون وتسجيل الحركات.
- دفعات جزئية ومتابعة المتبقي للمورد.
- تحديث سعر الشراء تلقائياً (متوسط موزون أو آخر سعر).

### العملاء
- قاعدة عملاء مع كشف حساب لكل عميل (مدين/دائن).
- تحصيل دفعات مباشرة من صفحة العملاء.
- ربط الفواتير بالعميل ومتابعة الرصيد المستحق.

### المصروفات
- تسجيل المصروفات بفئات قابلة للتخصيص.
- تمييز واضح: إيراد المبيعات / تكلفة البضاعة / الربح الإجمالي / المصروفات / صافي الربح.

### المخزون والحركات
- صفحة مخزون شاملة بقيمة التكلفة وقيمة البيع المتوقعة.
- سجل كامل لحركات المخزون (افتتاحي، بيع، شراء، مرتجع، يدوي، تسوية، استيراد).
- تسوية يدوية مع سبب وتوثيق.

### التقارير والتنبيهات
- تقارير بفلاتر زمنية (اليوم / 7 أيام / الشهر / السنة / مخصص).
- إجمالي المبيعات، الربح الإجمالي، صافي الربح، متوسط الفاتورة.
- أعلى المنتجات مبيعاً، رسوم بيانية (Chart.js) لطرق الدفع والمصروفات.
- تنبيهات تلقائية: مخزون منخفض، نفاد، قرب انتهاء، مستحقات.

### النسخ الاحتياطي والاستعادة
- نسخة JSON كاملة لكل البيانات (منتجات، فواتير، عملاء، إعدادات…).
- استعادة مع إنشاء نسخة وقائية تلقائياً قبل الاستبدال.
- خيار الدمج أو الاستبدال الكامل.

### Excel احترافي
- تصدير كل قسم على حدة أو **ملف Excel متعدد الأوراق** يحتوي كل البيانات.
- تنسيق احترافي: عناوين عربية، تجميد الصف الأول، فلاتر تلقائية، RTL، عرض أعمدة مناسب.
- الحفاظ على رموز المنتجات وأرقام الفواتير كنص (للحفاظ على الأصفار الأولى).
- منع حقن الصيغ (Formula Injection) في الحقول النصية.

## 🚀 التثبيت والاستخدام

### التشغيل محلياً (للتطوير)

```bash
cd store-app
python3 -m http.server 8080
# ثم افتح http://localhost:8080 في المتصفح
```

> **ملاحظة:** يجب تشغيل التطبيق عبر خادم HTTP (وليس `file://`) حتى يعمل **Service Worker** و **PWA** بشكل صحيح.

### النشر على GitHub Pages

1. ارفع مجلد `store-app` إلى مستودع GitHub.
2. اذهب إلى إعدادات المستودع: **Settings → Pages**.
3. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/store-app` (أو الجذر إذا رفعت المحتويات مباشرة).
4. انتظر دقيقة — سيكون التطبيق متاحاً على:
   ```
   https://<username>.github.io/<repo-name>/
   ```

### التثبيت كتطبيق على الهاتف (PWA)

1. افتح التطبيق على متصفح Chrome (أندرويد) أو Safari (iOS).
2. اضغط على قائمة المتصفح > **"تثبيت التطبيق"** / **"Add to Home Screen"**.
3. سيظهر التطبيق كأيقونة مستقلة على جهازك ويعمل **دون اتصال** بعد أول تحميل ناجح.

## 💾 النسخ الاحتياطي

> **مهم جداً:** البيانات تُخزَّن محلياً على الجهاز فقط. مسح بيانات المتصفح أو فقدان الجهاز يعني فقدان كل البيانات إن لم تُنشئ نسخة احتياطية.

### إنشاء نسخة احتياطية
1. اذهب إلى **الإعدادات → البيانات والنسخ**.
2. اضغط **"إنشاء نسخة احتياطية"**.
3. سيُنزَّل ملف `backup_<store>_<date>.json`.

### الاستعادة من نسخة
1. اذهب إلى **الإعدادات → البيانات والنسخ**.
2. اضغط **"استعادة من نسخة"**.
3. اختر ملف JSON.
4. راجع المعاينة واختر طريقة الاستعادة:
   - **استبدال**: يحذف كل شيء ويستبدل بالنسخة (مع نسخة وقائية تلقائية).
   - **دمج**: يدمج البيانات (تحديث بالمعرّف).

## 📥 استيراد المنتجات من Excel

1. اذهب إلى **الإعدادات → البيانات والنسخ → تنزيل القالب**.
2. افتح القالب في Excel/Google Sheets واملأ بياناتك (احذف صفوف الأمثلة).
3. ارجع للإعدادات واضغط **"استيراد منتجات"**.
4. اختر الملف.
5. راجع المعاينة (الأصناف الجديدة / الموجودة / الأخطاء).
6. اختر طريقة الدمج للمنتجات الموجودة (افتراضي: إضافة الكميات).
7. اضغط **"تنفيذ الاستيراد"**.
8. ستجد المنتجات في صفحة المنتجات والمخزون محدّثة، مع وجود سجل في صفحة المخزون → تسوية.

## 🖨️ طباعة الفواتير وحفظ PDF ومشاركة واتساب

من أي فاتورة (في صفحة الفواتير أو بعد إتمام البيع):

| الزر | الوظيفة |
|------|---------|
| **طباعة** | يفتح نافذة الطباعة (يمكن اختيار A4 أو حرارية 80mm). |
| **حفظ PDF** | يفتح نافذة الطباعة — اختر "حفظ كـ PDF" كطابعة. |
| **مشاركة واتساب** | يفتح محادثة واتساب برقم العميل مع رسالة تتضمن تفاصيل الفاتورة. |

يمكنك تغيير صيغة الفاتورة الافتراضية من **الإعدادات → صيغة الفاتورة الافتراضية**.

## ⚙️ الإعدادات الأساسية

في صفحة **الإعدادات**:

- **بيانات المتجر**: الاسم، الهاتف، العنوان، الشعار، رمز واتساب، العملة، سياسة الإرجاع.
- **إعدادات البيع**: الضريبة (نسبة / شاملة)، بادئة الفاتورة، رقم الفاتورة التالي، طريقة الدفع الافتراضية، الحد الأدنى للمخزون، أيام التنبيه للانتهاء، السماح بمخزون سالب، متوسط التكلفة الموزون.
- **البيانات والنسخ**: تنزيل قالب، استيراد/تصدير Excel، نسخ احتياطي، استعادة، حذف كل البيانات.

## 🔒 الخصوصية والعمل دون اتصال

- كل البيانات تُخزَّن **محلياً على جهازك** في `IndexedDB`.
- لا يوجد أي إرسال للبيانات إلى خوادم خارجية.
- التطبيق يعمل **دون اتصال بالإنترنت** بعد أول تحميل.
- المكتبات الخارجية (SheetJS, Chart.js, خط Cairo) تُحمَّل من CDN عند أول استخدام، ثم يخزنها Service Worker للاستخدام دون اتصال.
- ميزة مشاركة واتساب تتطلب اتصالاً بالإنترنت وتطبيق واتساب على الجهاز.

## 🧮 قواعد الحساب المحاسبية

- **الإجمالي الفرعي للسطر**: الكمية × سعر الوحدة − خصم السطر.
- **إجمالي الفاتورة**: الإجمالي الفرعي − الخصم الإجمالي + الضريبة.
- **المتبقي**: الإجمالي − المدفوع.
- **الصرف**: المدفوع − الإجمالي (إذا زاد المدفوع عن الإجمالي).
- **تكلفة البضاعة المباعة (COGS)**: مجموع (تكلفة الوحدة × الكمية المباعة) من لقطة الفاتورة.
- **الربح الإجمالي**: إيراد المبيعات − تكلفة البضاعة المباعة.
- **صافي الربح**: الربح الإجمالي − المصروفات.
- **طريقة التكلفة**: متوسط موزون (افتراضي) أو آخر سعر شراء.

> **ملاحظة محاسبية:** لا يتم احتساب الأرصدة المستحقة (غير المدفوعة) كنقد مُحصَّل. المرتجعات تُعكس بشكل صحيح من الإيراد والتكلفة والرصيد.

## ⚠️ القيود المعروفة

1. **لا يوجد مزامنة سحابية**: البيانات محلية بالكامل. لا يمكن الوصول لها من أجهزة مختلفة.
2. **Service Worker تحت file://**: لا يعمل SW على بروتوكول `file://` — يجب تشغيله عبر HTTP/HTTPS.
3. **مشاركة PDF عبر واتساب**: تختلف حسب دعم المتصفح لـ Web Share API. عند عدم توفرها، يتم تنزيل PDF وإرشاد المستخدم لإرفاقه يدوياً.
4. **CDN**: المكتبات الخارجية تحتاج اتصال إنترنت لأول تحميل، ثم تُخزَّن محلياً.
5. **حجم التخزين**: قد يصل حد التخزين في المتصفح إلى حدوده (عادةً عدة ميغابايت، ويمكن أن تطلب المتصفحات إذناً لاستخدام مساحة أكبر).
